## 新建 PySide6 Dracula 版本（独立目录）
- **位置**：`interfaces/pyside6_dracula/`（独立于 pyqt6_ui/）
- **内容**：将 PyDracula（PyQt6）整体移植为 PySide6，主要差异：
  - 所有 `from PyQt6.xxx import *` → `from PySide6.xxx import *`
  - `pyqtSignal` → `Signal`（PySide6 内置在 `PySide6.QtCore`）
  - `QEvent.MouseButtonDblClick` → `QEvent.Type.MouseButtonDblClick`
- **入口**：`python main.py --ui pyside6` 或直接 `python run_pyside6_dracula.py`
- **独立脚本**：`run_pyside6_dracula.py`（项目根目录）
